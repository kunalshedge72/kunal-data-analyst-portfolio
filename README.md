# Kunal Shedge — Data Analyst Portfolio

A responsive dark-theme portfolio website built with plain HTML, CSS and vanilla JavaScript.

## Included
- `index.html` — portfolio content and sections
- `styles.css` — responsive styling, layout and motion effects
- `script.js` — mobile navigation, reveal animations and current footer year

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in a modern browser.
3. An internet connection is needed for the Google Fonts import; the site otherwise runs without a build step or package installation.

## Publish using GitHub Pages
1. Create a new public GitHub repository, for example `kunal-data-analyst-portfolio`.
2. Upload the three website files and this README to the repository root.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the website. The published URL will appear in the Pages settings.
